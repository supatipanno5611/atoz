# 기록 패널 리뉴얼

수면 기록 패널(`Daynight.ts`)을 수면·식사·타임라인·가계부 기록을 모두 맡는 패널로 바꾼다.
대신 입력은 아주 간단하게 한다.

## 지금 상태 (2026-10-28)

| 기록 | 입력 방식 | 필요한 값 |
|---|---|---|
| 수면 | 패널 버튼 한 번 | 없음 (시각은 지금) |
| 식사 | 모달 (명령어로 열기) | 날짜, 시각, 음식, 범례 |
| 가계부 | 모달 | 수입/지출, 날짜, 항목(필수), 카테고리, 금액, 메모 |
| 타임라인 기록 | 입력 UI 없음, `log-YYYY-MM.md`에 직접 씀 | 날짜, 시각, 카테고리, 메모 |

수면 패널에 있던 24시간 그래프와 구간 이동은 수면 대시보드의 '24시간' 카드로 옮겼다.
패널에는 현재 상태, 최근 기록, 바로가기, 자기/일어나기 버튼만 남았다.

## 정한 것

- 원칙: 저장은 버튼 한 번, 다듬기는 나중에. 시각은 항상 '지금'이다.
- 수면은 타임라인에 합치지 않는다. 저장은 지금처럼 따로 한다.
- 가계부 항목명은 생략할 수 있게 한다. 나중에 보면서 고친다.
- 시각 보정 버튼("10분 전" 등)은 만들지 않는다.
- 계획은 이 패널에서 받지 않는다. 대시보드 계획 페이지([plan-page.md](plan-page.md))에서 세운다.
- 버튼 수는 목업을 보면서 정한다.

## 처음 낸 구성안 (목업으로 확인할 것)

1. 지금 상태: "공부 중 · 1시간 20분" / "자는 중 · 6시간 10분"
2. 빠른 버튼
   - 타임라인 카테고리: 누르면 그 활동 시작
   - 식사 범례: 누르면 지금 식사 (음식 이름은 비워도 됨)
   - 가계부: 카테고리를 누르면 금액 칸만 열림
   - 자기/일어나기
3. 오늘 기록: 네 종류를 시간순으로 섞어 한 줄씩. 시각 고치기, 메모, 지우기는 여기서 한다.

# 계획 페이지

대시보드에 하루 계획을 세우는 페이지를 새로 둔다. 계획은 하루치를 한꺼번에 세운다는 전제다.
핵심은 저장해 둔 할 일 블록을 꺼내 순서대로 쌓아 하루를 조립하는 것이다.

목업: https://claude.ai/artifact/38h2WKygGnxC71PXveAi1N (왼쪽 "B+① 세 줄 트레이"가 채택안)

## 지금 상태 (2026-10-28)

- 계획은 `timeline/plan-YYYY-MM.md`에 손으로 쓴다. 입력 UI는 없다.
- 형식: `| 2026-10-28 | 09:00 | 12:00 | 공부 | 메모 |` (날짜, 시작, 끝, 카테고리, 메모). 끝이 시작보다 이르면 자정을 넘긴 계획이다.
- 타임라인 페이지가 계획과 기록을 나란히 그리고, 같은 카테고리끼리 겹친 시간으로 일치율을 낸다.
- 카테고리 목록은 따로 없다. 파일에 쓴 글자가 곧 카테고리다. 카테고리 색은 설정 데이터(`timelineColors`)에만 있고 고치는 UI가 없다.

## 정한 것

### 파일

`timeline/blocks.md`: 다시 쓰는 블록. 이름이 곧 계획의 카테고리다.

```
| Name | Minutes | Repeat |
| --- | --- | --- |
| 씻고 운동하기 | 60 | 월,수,금 |
| 알고리즘 공부 | 90 | |
| 휴식 | | |
```

- 블록은 할 일 하나다.
- 기록 패널의 활동 버튼도 이 목록을 쓴다. 그래서 휴식, 이동처럼 기록용 블록도 여기에 둔다.
- `Minutes`는 선택이다. 기록에는 쓰지 않고 계획에 쌓을 때만 쓴다. 비어 있으면 계획에 넣을 때 30분으로 쌓는다. 여러 일을 묶는 기능은 두지 않는다. 필요하면 이름을 "씻고 운동하기"처럼 쓴다.
- 메모 칸은 두지 않는다. 그날 메모는 계획을 세울 때 적는다.
- `Repeat` 요일에는 '오늘' 줄에 추천으로만 뜬다. 계획에 넣을지는 그날 사람이 고른다. 가져가도 블록은 남는다.

`timeline/later.md`: 한 번만 쓰는 할 일.

```
| Date | Name | Minutes | Memo |
| --- | --- | --- | --- |
| | 보고서 마무리 | 120 | 10/28에서 미룸 |
| 2026-11-03 | 병원 | 60 | |
```

- 날짜가 비면 미룬 일, 있으면 그날 '오늘' 줄에 뜨는 예약이다.
- 계획에 넣으면 이 파일에서 줄을 지운다. 계획에서 다시 빼면 돌아온다.

계획 결과는 지금처럼 `plan-YYYY-MM.md`에 쓴다. 저장하면 그 날짜의 줄을 통째로 바꾼다. 그래서 타임라인 페이지는 그대로 둔다.

### 화면

- 왼쪽: 하루 미리보기. 쌓은 블록이 있는 시간대만 앞뒤 1시간 여유를 두고 그린다.
- 오른쪽 위: 알약 트레이. 탭 없이 세 줄로 나눈다.
  - 오늘: 그 요일 반복 블록 + 오늘 예약
  - 미룬 일
  - 블록: 나머지 블록 + 새 블록 `+`
- 알약은 `● 이름 분`. 반복 요일은 툴팁, 이미 넣은 반복 블록은 흐리게, 한 번만 쓰는 할 일은 점선 테두리.
- 오른쪽 아래: 계획 목록. 시작 시각 하나를 정하면 블록이 순서대로 이어 붙는다(쌓기 방식).
  - 블록마다 끌어서 순서 바꾸기, ±15분, 시각 고정, 메모, 빼기. 위/아래 버튼은 두지 않는다.
  - 시각을 고정한 블록 앞의 남는 시간은 '빈 시간'으로, 앞 블록과 겹치면 경고로 보인다.

### 미루기

- 지난 날 계획을 열어 블록마다 '미루기'를 직접 누른다. 자동으로 판단하지 않는다.
- 누르면 `later.md`에 날짜 없이 "MM/DD에서 미룸" 메모와 함께 들어간다.
- 원래 계획 줄은 지우지 않는다. 그날 일치율이 원래 계획 기준으로 남게 하려는 것이다.

## 남은 것

- 기록 패널 활동 `+` 버튼이 지금은 `blocks.md`를 연다. 이 페이지가 생기면 메인 탭에 이 페이지를 열게 바꾼다

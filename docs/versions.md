# 버전 관리

## 역할

노트의 현재 본문을 별도의 버전 노트로 저장하고, 저장한 버전으로 되돌리거나 두 시점의 본문을 비교합니다.

## 사용 방법

- `버전: 현재 상태 저장`: 현재 노트의 본문을 새 버전 노트로 저장합니다.
- `버전: 저장한 버전으로 되돌리기`: 저장된 버전 목록에서 하나를 골라 현재 노트의 본문을 그 버전으로 바꿉니다.
- `버전: 비교 창 열기`: 메인 작업 영역에 버전 비교 탭을 열어 두 시점의 본문 차이를 보여 줍니다.

## 버전 노트

- 파일 이름은 `<이름>_<YYYYMMDDHHmmss>.md`입니다. 처음 저장할 때 이름은 번호이며, 숫자로 된 기존 버전 이름 중 가장 큰 번호에 1을 더합니다. 예: `3_20261006143000.md`
- 설정의 `버전 노트 대상 폴더`에 만들며, 비어 있으면 원본과 같은 폴더에 만듭니다. 폴더가 없으면 만듭니다.
- 버전 노트에는 원본의 frontmatter를 복사하지 않고 본문만 저장합니다. frontmatter에는 원본을 가리키는 `version: "[[원본 노트]]"` 하나만 기록합니다.
- 원본과의 연결은 파일 이름이 아니라 `version` 링크가 가리키는 실제 파일을 기준으로 판단합니다.
- 저장은 디스크가 아니라 편집기에 열려 있는 현재 내용을 기준으로 합니다.

## 되돌리기

- 현재 노트의 frontmatter는 그대로 두고 본문만 선택한 버전의 본문으로 바꿉니다.
- 편집기 안에서 바꾸므로 실행 취소(Ctrl+Z)로 되돌릴 수 있습니다.
- 되돌리기 전에 현재 상태를 자동으로 저장하지 않습니다. 필요하면 먼저 `버전: 현재 상태 저장`을 실행하세요.

## 비교 창

- 상단에 원본 이름과 `이전 → 이후` 버튼을 표시합니다. 각 버튼을 누르면 비교할 시점을 고를 수 있으며, 이전 쪽은 이후보다 앞선 시점만 고를 수 있습니다.
- 비교할 수 있는 시점은 `빈 노트`, 저장된 버전들(오래된 순), `현재 노트 상태`입니다. 처음 열면 가장 최근 버전과 현재 노트를 비교합니다.
- 왼쪽 목록에서 행을 누르면 그 시점과 바로 앞 시점을 비교합니다. 이미 선택된 행의 버전 이름을 다시 누르면 이름을 바꿀 수 있습니다. Enter로 저장하고 Esc로 취소합니다. 이름을 바꿔도 파일 이름 끝의 시각은 유지됩니다.
- 목록 아이콘으로 버전 목록을 접거나 펼치고, 새로고침 아이콘으로 두 시점을 다시 읽습니다.
- 차이는 한 화면에 이어서 표시합니다. 문단 단위로 비교한 뒤 바뀐 문단은 줄·단어·글자 단위까지 좁혀서 지운 부분과 추가된 부분을 표시합니다.
- 위치만 옮겨진 문단에는 `이동됨` 표시를 붙입니다.
- 바뀐 문단의 앞뒤 한 문단만 남기고, 나머지 바뀌지 않은 문단은 `변경 없는 문단 N개 생략`으로 접습니다.

## 제약

- 세 명령 모두 활성 마크다운 노트에서만 사용할 수 있고, 버전 노트 자체에서는 사용할 수 없습니다.
- 저장된 버전이 없으면 되돌리기와 비교 창을 열 수 없습니다.
- 버전 노트는 `주제어 편집` 후보와 노트 목록에서 제외됩니다.

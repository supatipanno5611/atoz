# 작업 문서

## 역할

설정된 작업 문서를 메인 작업 영역에서 빠르게 엽니다. 작업 문서의 내용도 다른 노트와 동일하게 원본별 Later 기능으로 보관합니다.

## 제공 기능

- `작업 문서 열기`: 설정된 작업 문서를 메인 작업 영역에서 엽니다.
- `모든 탭 닫기`: 메인 작업 영역의 고정되지 않은 탭을 닫습니다.
- 리본 아이콘으로 작업 문서를 바로 열 수 있습니다.
- `work.md`에서 `선택한 행을 Later로 이동`을 실행하면 `work_later.md`에 저장됩니다.

## 설정 및 제약

- 작업 문서 경로는 설정값을 사용합니다.
- 작업 문서 파일이 없으면 열기 명령을 수행하지 않습니다.
- 전역 `later.md`는 특별하게 취급하지 않으며 기존 파일과 내용도 변경하지 않습니다.

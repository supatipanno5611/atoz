# 노트 목록

## 역할

frontmatter에 `notelist: true`가 있는 노트의 본문을, 그 노트를 링크하는 모든 노트의 목록으로 자동으로 채웁니다.

## 사용 방법

1. 목록으로 쓸 노트의 frontmatter에 `notelist: true`를 넣습니다.
2. Obsidian을 다시 시작하거나 `노트 목록: 모두 새로 고치기`를 실행합니다.
3. 본문이 아래처럼 바뀝니다.

```md
---
notelist: true
---
- [[글쓰기 습관]]
- [[문장 다듬기]]
```

## 동작 및 제약

- 그 노트로 향하는 링크가 있는 마크다운 노트를 모아 파일 이름순으로 정렬합니다. `topics` 같은 속성 안의 링크도 포함됩니다.
- 노트 자신, 설정된 작업 노트, Later 노트(`later` 속성), 버전 노트(`version` 속성)는 목록에 넣지 않습니다.
- 목록은 플러그인을 불러올 때 한 번, 그리고 명령을 실행할 때 갱신합니다. 링크가 바뀔 때마다 자동으로 갱신하지는 않습니다.
- 본문이 비어 있거나 `- [[링크]]` 형식의 행과 빈 행만 있을 때만 덮어씁니다. 직접 쓴 내용이 한 줄이라도 있으면 그 노트는 건너뛰고 몇 개를 건너뛰었는지 알림으로 알려 줍니다.
- frontmatter가 없는 노트는 대상이 아닙니다. `notelist` 값은 정확히 `true`여야 합니다.
- 바뀐 목록이 있을 때만 파일을 수정합니다. 명령으로 실행하면 바뀐 노트가 없어도 결과를 알림으로 보여 줍니다.

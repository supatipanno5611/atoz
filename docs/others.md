# 기타 기능

## 사이드바 탭 순환

- `왼쪽 사이드바: 다음 탭`, `왼쪽 사이드바: 이전 탭`, `오른쪽 사이드바: 다음 탭`, `오른쪽 사이드바: 이전 탭` 명령으로 사이드바의 탭을 차례로 넘깁니다.
- 마지막 탭에서 다음으로 가면 첫 탭으로, 첫 탭에서 이전으로 가면 마지막 탭으로 돌아갑니다.
- 단축키를 지정해 두면 마우스 없이 파일 탐색기, Later, 노트 정보 같은 사이드바 탭을 오갈 수 있습니다.

## 사이드바 독립 리본

- 모바일과 태블릿에서 왼쪽 사이드바가 닫혀 있을 때 리본 메뉴를 화면 왼쪽에 고정해 보여 줍니다. 사이드바를 열면 리본이 원래 자리로 돌아갑니다.
- 설정의 `사이드바 독립 리본 사용` 또는 `사이드바 독립 리본 켜기/끄기` 명령으로 켜고 끕니다. 상태는 설정에 저장됩니다.
- 데스크톱에서는 동작하지 않습니다.

## 파일 메뉴 항목

마크다운 파일의 파일 메뉴(탭 제목이나 파일 탐색기에서 여는 메뉴)에 다음 항목을 추가합니다.

| 항목 | 표시 조건 | 동작 |
| --- | --- | --- |
| `저장` | 현재 열려 있는 파일 | 편집기의 현재 내용을 파일에 바로 씁니다. |
| `퀵 슬롯: 현재 파일 넣기/빼기` | 현재 열려 있는 파일 | 퀵 슬롯 지정 창을 엽니다. |
| `현재 파일 이동` | 현재 열려 있는 파일 | 현재 파일 이동 창을 엽니다. |
| `노트 전체 복사` | 모든 마크다운 파일 | 메뉴를 연 파일의 전체 내용을 클립보드에 복사합니다. |

## 활성 탭 북마크

- 북마크 모양 리본 아이콘을 누르면 현재 탭을 Obsidian 북마크에 추가합니다.
- Obsidian의 핵심 플러그인 `북마크`가 켜져 있어야 합니다. 꺼져 있으면 켜 달라는 알림을 표시합니다.

## 한글 입력 버그 픽스

### 왜 필요한가요?

안드로이드의 Obsidian에서 한글을 입력하다 보면 `고`가 `ㄱㅗ`처럼 자음과 모음이 따로 입력되는 일이 종종 생깁니다. 이 기능은 이런 상태가 됐을 때 입력 조합 상태를 초기화하기 위해 있습니다.

한글은 키보드 앱(IME)이 `ㄱ`, `ㅗ`를 받아 `고`로 합치는 "조합" 과정을 거칩니다. 키보드 앱은 조합 중인 글자를 편집기에 알려 주고, 편집기는 조합이 끝났다는 신호(`compositionend`)를 받아야 글자를 확정합니다. 둘이 기억하는 조합 상태가 어긋나면 키보드 앱이 자모를 하나씩 따로 확정해 버리고, 그때부터 글자가 `ㄱㅗ`처럼 풀어져 입력됩니다.

이 문제는 Obsidian만의 문제가 아니라, 웹 기술로 만든 편집기를 쓰는 여러 안드로이드 앱에서 삼성 키보드 등과 함께 보고되는 문제입니다. Obsidian 포럼에서도 안드로이드 키보드와 한·중·일 입력이 어긋나는 문제가 보고되어 있고, Obsidian 팀은 알고 있으며 고치겠다고 답했습니다. 아직 근본적으로 해결되지 않아 이 기능으로 보완합니다.

### 어떻게 동작하나요?

- 플러그인은 편집기의 조합 시작(`compositionstart`)과 조합 끝(`compositionend`) 신호를 지켜보며 지금 조합 중인지 기억합니다.
- 조합 중에 편집기를 터치하거나 클릭하면, 또는 방향키·Home·End·PageUp·PageDown을 누르면 편집기에 조합 끝 신호를 직접 보내 조합 상태를 정리합니다. 키보드 앱과 편집기가 기억하는 조합 상태가 서로 어긋난 채로 남지 않게 하려는 것입니다.
- 조합 중이 아닐 때는 아무 일도 하지 않습니다.
- 코드에서 플랫폼을 구분하지 않으므로 데스크톱과 iOS에서도 같은 방식으로 동작합니다.

### 자모가 풀어져 입력될 때

1. 입력 중인 곳을 한 번 터치합니다. 조합 중이었다면 플러그인이 조합 끝 신호를 보내 상태를 정리합니다.
2. 그래도 계속되면 `한글 입력 버그 픽스 기능 재시작`을 실행합니다.
3. 이미 `ㄱㅗ`처럼 입력된 글자는 자동으로 합쳐지지 않으므로 지우고 다시 입력합니다.
4. 자주 반복되면 키보드 앱의 자동 완성(예측 입력)을 끄거나 다른 키보드 앱을 써 보세요. Obsidian 포럼에서 안내하는 우회 방법입니다.

### 켜지는 시점

- Obsidian을 시작하면 다른 플러그인이 모두 불러와지고 작업 영역이 준비될 때까지 기다린 뒤 켜집니다. 켜지면 `옵시디언 준비 완료` 알림을 한 번 표시합니다.
- 따로 끄는 설정은 없습니다.

### 재시작 명령

- `한글 입력 버그 픽스 기능 재시작`은 플러그인이 기억하던 조합 상태를 "조합 중 아님"으로 비우고, 잠시 뒤 기능을 다시 켭니다. 완료되면 알림을 표시합니다.
- 플러그인의 기억이 실제 입력 상태와 어긋나 위 동작이 제대로 일어나지 않을 때 쓰는 명령입니다.
- 키보드 앱 자체를 다시 시작하지는 않습니다.

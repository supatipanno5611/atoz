# 기타 기능

## 사이드바 탭 순환

- `왼쪽 사이드바: 다음 탭`, `왼쪽 사이드바: 이전 탭`, `오른쪽 사이드바: 다음 탭`, `오른쪽 사이드바: 이전 탭` 명령으로 사이드바의 탭을 차례로 넘깁니다.
- 마지막 탭에서 다음으로 가면 첫 탭으로, 첫 탭에서 이전으로 가면 마지막 탭으로 돌아갑니다.
- 단축키를 지정해 두면 마우스 없이 파일 탐색기, Later, 문서 정보 같은 사이드바 탭을 오갈 수 있습니다.

## 사이드바 독립 리본

- 모바일과 태블릿에서 왼쪽 사이드바가 닫혀 있을 때 리본 메뉴를 화면 왼쪽에 고정해 보여 줍니다. 사이드바를 열면 리본이 원래 자리로 돌아갑니다.
- 설정의 `사이드바 독립 리본 사용` 또는 `사이드바 독립 리본 토글` 명령으로 켜고 끕니다. 상태는 설정에 저장됩니다.
- 데스크톱에서는 동작하지 않습니다.

## 파일 메뉴 항목

마크다운 파일의 파일 메뉴(탭 제목이나 파일 탐색기에서 여는 메뉴)에 다음 항목을 추가합니다.

| 항목 | 표시 조건 | 동작 |
| --- | --- | --- |
| `저장` | 현재 열려 있는 파일 | 편집기의 현재 내용을 파일에 바로 씁니다. |
| `퀵 슬롯 지정 메뉴 열기` | 현재 열려 있는 파일 | 퀵 슬롯 지정 창을 엽니다. |
| `현재 파일 이동` | 현재 열려 있는 파일 | 현재 파일 이동 창을 엽니다. |
| `문서 전체 복사` | 모든 마크다운 파일 | 메뉴를 연 파일의 전체 내용을 클립보드에 복사합니다. |

## 활성 탭 북마크

- 북마크 모양 리본 아이콘을 누르면 현재 탭을 Obsidian 북마크에 추가합니다.
- Obsidian의 핵심 플러그인 `북마크`가 켜져 있어야 합니다. 꺼져 있으면 켜 달라는 알림을 표시합니다.

## 한글 입력 버그 픽스

### 왜 필요한가요?

Obsidian 편집기에서 한글을 쓰다 보면, 글자를 조합하는 도중에 다른 곳을 클릭하거나 방향키로 커서를 옮길 때 마지막 글자가 엉뚱하게 처리되는 일이 있습니다. 예를 들어 마지막 글자가 한 번 더 입력되거나 옮겨 간 커서 위치에 따라 붙는 식입니다.

원인은 한글 입력기가 아직 끝나지 않은 글자를 "조합 중" 상태로 들고 있는데, 편집기는 그 상태가 끝나기 전에 커서를 먼저 옮기기 때문입니다. 영어처럼 조합이 없는 언어에서는 생기지 않고, 한글·일본어·중국어처럼 조합해서 입력하는 언어에서 주로 생깁니다.

### 어떻게 동작하나요?

- 한글을 조합하는 중에 편집기를 클릭하거나 터치하면, 또는 방향키·Home·End·PageUp·PageDown을 누르면 커서가 움직이기 전에 조합을 먼저 끝냅니다.
- 그래서 조합 중이던 글자가 원래 자리에서 확정된 뒤에 커서가 옮겨 갑니다.
- 조합 중이 아닐 때는 아무 일도 하지 않습니다.

### 켜지는 시점

- Obsidian을 시작하면 다른 플러그인이 모두 불러와지고 작업 영역이 준비될 때까지 기다린 뒤 켜집니다. 켜지면 `옵시디언 준비 완료` 알림을 한 번 표시합니다.
- 시작 직후의 불안정한 상태에서 다른 플러그인이나 편집기와 충돌하지 않도록 이렇게 늦춰 둡니다.
- 따로 끄는 설정은 없습니다.

### 재시작 명령

- 조합 상태를 잘못 기억해 입력이 이상해지면 `한글 입력 버그 픽스 기능 재시작`을 실행합니다.
- 기억하던 조합 상태를 비우고 잠시 뒤 다시 켭니다. 완료되면 알림을 표시합니다.

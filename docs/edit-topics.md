# 주제어 편집

## 역할

현재 마크다운 파일의 `topics` frontmatter 위키링크를 추가하거나 제거하고, 저장된 링크의 별칭을 변경합니다.

## 사용 방법

- 명령 팔레트에서 `주제어 편집`을 실행합니다.
- vault의 모든 마크다운 노트를 노트 이름, 경로 또는 `aliases`로 검색해 선택하거나, 입력한 새 주제어를 추가합니다.
- `[선택됨]`으로 표시된 주제어를 고르면 현재 문서에서 제거됩니다.
- 같은 대상을 다른 별칭으로 검색해 `[별칭 변경]` 항목을 고르면 중복 추가하지 않고 기존 링크의 별칭을 바꿉니다.
- 노트 후보를 강조한 상태에서 `:`를 입력하면 표시된 노트 이름, 경로 또는 별칭으로 검색어가 자동완성됩니다. 이어서 `#` 또는 `^`를 입력해 세부 후보를 열 수 있습니다.
- `노트 이름#`을 입력하면 해당 노트의 제목을, `노트 이름^`을 입력하면 명시적인 블록 ID가 있는 블록을 검색합니다.

## 동작 및 제약

- 현재 문서에 `topics`가 없으면 빈 배열을 먼저 만듭니다.
- 새 주제어는 `"[[주제어]]"` 형식으로 저장됩니다. 등록된 별칭으로 선택하면 `"[[노트 경로|별칭]]"` 형식으로 저장됩니다.
- 제목 링크와 블록 링크도 사용할 수 있으며, 노트 경로와 세부 위치가 모두 같을 때 같은 대상으로 판단합니다.
- 제목은 제목 문자로, 블록은 블록 ID와 최대 80자의 본문 미리보기로 검색할 수 있습니다. `노트 이름^블록ID` 입력은 `"[[노트 이름#^블록ID]]"`로 저장됩니다.
- 현재 노트, `later` 속성이 있는 Later 노트, 설정된 작업 노트와 vault 루트의 `log.md`는 자동 후보에서 제외됩니다. 현재 문서에 이미 저장된 제외 대상은 제거하거나 변경할 수 있고, 완전한 링크를 직접 입력해 추가할 수도 있습니다.
- `#` 또는 `^` 앞에는 정확한 노트 이름, 경로 또는 별칭을 입력해야 세부 후보가 열립니다. 같은 이름이나 별칭을 가진 노트가 여러 개면 실제 경로를 함께 표시합니다.
- 같은 노트에 같은 이름의 제목이 반복되면 후보에는 한 번만 표시합니다. 블록 후보에는 이미 ID가 있는 블록만 포함하며 대상 노트에 새 블록 ID를 만들지는 않습니다.
- 존재하지 않는 노트 이름 뒤에 `#` 또는 `^`만 입력하면 추가하지 않습니다. 세부 위치까지 완전히 입력한 미해결 링크는 추가할 수 있습니다.
- 후보에는 위키링크 괄호를 숨기고, 별칭과 실제 대상이 다르면 대상 경로를 함께 표시합니다.
- 기존 일반 문자열 주제어는 일괄 변경하지 않으며, 모달에서 새로 추가하거나 변경할 때만 위키링크로 저장됩니다.
- 주제어는 화면에 표시되는 이름을 기준으로 정렬되어 저장됩니다.
- 현재 활성 마크다운 파일에서 사용할 수 있습니다.

예를 들어 `글쓰기` 별칭으로 제목이나 블록을 선택하면 각각 `"[[Writing#문학|글쓰기#문학]]"`, `"[[Writing#^important-block|글쓰기^important-block]]"`처럼 저장됩니다.

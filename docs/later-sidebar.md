# Later 사이드바

## 역할

현재 노트에서 잠시 미뤄 둔 문장을 원본별 Later 노트에 보관하고, 오른쪽 사이드바에서 다시 선택해 가져옵니다.

## 연결 규칙

- 원본 노트와 Later 노트는 1대1로 연결합니다.
- 새 Later 노트의 파일명은 `<원본명>_later.md`로 고정합니다.
- 설정한 Later 노트 대상 폴더에 생성하며, 폴더 설정이 비어 있으면 vault 루트에 생성합니다.
- Later 노트의 frontmatter에는 `later: "[[원본 노트]]"` 형식의 단일 위키링크를 기록합니다.
- 연결은 Later 파일명이 아니라 `later` 링크가 가리키는 실제 파일을 기준으로 판단합니다.
- 원본 파일명이 바뀌어도 기존 Later 파일명은 유지합니다.
- 같은 원본에 연결된 Later 노트가 여러 개면 사용자가 하나를 선택하고, 선택하지 않은 파일에서는 `later` 속성을 삭제합니다. 파일과 본문은 삭제하지 않습니다.
- 끊어진 링크는 파일명으로 추측해 자동 복구하지 않습니다.

## 문장 보내기

- 선택 영역이 없으면 현재 행을 Later 노트로 보냅니다.
- 여러 행을 선택하면 선택이 걸친 전체 행을 한 번에 보냅니다.
- 선택 범위에 frontmatter가 포함돼도 frontmatter는 원본에 남기고 본문 행만 보냅니다.
- Markdown 목록, 인용, 체크박스 기호를 정리한 각 비어 있지 않은 행을 독립 항목으로 저장합니다.
- Later 기록이 성공한 뒤에만 원본 행을 제거합니다.
- 기존 `_later.md`에 `later` 속성이 없으면 처음 다시 사용할 때 연결 속성을 추가합니다.
- `later` 속성이 있는 노트에서는 다시 Later 노트를 만들 수 없습니다.
- `work.md`도 같은 규칙을 사용해 `work_later.md`와 연결합니다.

## 사이드바와 가져오기

- frontmatter와 빈 행을 제외한 Later 본문의 각 행을 선택 가능한 항목으로 표시합니다.
- 목록의 행 높이, 글자 크기, hover 배경, 선택 강조, 자동 스크롤과 한 줄 말줄임 디자인은 클립보드 사이드바와 동일하게 유지합니다.
- Later에는 클립보드의 핀 고정, 순서 변경, 삭제와 우클릭 관리 메뉴를 제공하지 않습니다.
- 항목은 마우스 또는 이전·다음 명령으로 선택합니다.
- 가져오기는 Later 문장을 삭제하지 않고 연결된 원본 노트의 현재 커서 또는 선택 영역에 복사합니다.
- 원본 노트가 열려 있지 않으면 root leaf에 연 뒤 문서 끝에 삽입합니다.
- Later 노트를 보고 있을 때는 연결된 원본 제목을 링크로 표시합니다. 링크를 누르면 원본을 root leaf에서 열고 포커스합니다.

## 공용 사이드바 명령

다음 세 명령은 기존 클립보드 명령 ID를 유지하면서 클립보드와 Later 사이드바가 공유합니다.

- `사이드바 이전 항목 선택`
- `사이드바 다음 항목 선택`
- `사이드바 선택 항목 가져오기`

오른쪽 사이드바에서 클립보드 탭을 선택하면 클립보드에, Later 탭을 선택하면 Later에 작동합니다. 다른 종류의 사이드바 탭이 선택돼 있으면 실행하지 않습니다.

# 문서 정보

`문서 정보 보기` 명령이나 리본 아이콘으로 왼쪽 사이드바에 현재 문서의 통계를 표시합니다.

표시 순서는 다음과 같습니다.

1. 공백 포함 글자 수
2. 공백 제외 글자 수
3. 글자가 있는 행 개수
4. 읽는 시간(분)
5. 목표 글자 수

목표 글자 수는 현재 문서에 목표가 지정된 경우에만 표시됩니다. 문서 정보 상단의 `목표 지정` 과녁 버튼이나 `현재 문서 목표 글자수 지정` 명령으로 설정에 등록된 후보를 선택할 수 있습니다.

선택한 목표와 오차범위는 문서 frontmatter에 함께 저장됩니다.

```yaml
---
target-characters: 2000
target-tolerance: 100
---
```

목표 글자 수는 공백 포함 글자 수를 기준으로 계산합니다. 목표가 `2,000자`, 오차가 `100자`라면 `1,900자`부터 `2,100자`까지 안전 범위입니다. 목표보다 부족하면 `+ 72자`, 초과하면 `- 102자`처럼 정확한 목표와의 차이를 표시합니다.

읽는 시간은 설정한 공백 포함·제외 기준과 분당 읽는 글자 수를 사용합니다. 기본값은 공백 제외, 분당 500자입니다. 가장 가까운 정수로 반올림하고 1분 미만은 `1`로 표시합니다. 단위는 항목 이름 `읽는 시간(분)`에서 제공합니다.

글자 수를 계산할 때 frontmatter, 코드 블록, 이미지와 임베드, 수식, 태그, 각주는 제외합니다.

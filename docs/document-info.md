# 문서 정보

`문서 정보 보기` 명령이나 리본 아이콘으로 왼쪽 사이드바에 현재 문서의 통계를 표시합니다.

표시 순서는 다음과 같습니다.

1. 공백 포함 글자 수
2. 공백 제외 글자 수
3. 글자가 있는 행 개수
4. 읽는 시간(분)
5. 목표 글자 수

편집 모드에서 텍스트를 선택하면 공백 포함·제외 글자 수가 `128 / 2,340`처럼 `선택 / 전체` 형식으로 바뀝니다. 여러 곳을 선택하면 합산합니다. 행 개수, 읽는 시간, 목표 글자 수는 선택과 관계없이 문서 전체를 기준으로 합니다. 마크다운 문법의 중간까지만 선택하면 선택한 부분만 따로 해석하므로 문서 안에서 보이는 모습과 글자 수가 조금 다를 수 있습니다.

목표 글자 수는 현재 문서에 목표가 지정된 경우에만 표시됩니다. 문서 정보 상단의 과녁 아이콘이나 `현재 문서 목표 글자수 지정` 명령으로 목표를 지정하거나 기존 목표를 해제할 수 있습니다.

목표는 다음 세 종류 중 하나로 지정합니다. 한 문서에는 한 종류만 지정할 수 있습니다.

| 종류 | frontmatter | 항목 이름 |
| --- | --- | --- |
| 범위 | `target-characters`, `target-tolerance` | 목표 글자 수 |
| 이상 | `min-characters` | 최소 글자 수 |
| 이하 | `max-characters` | 최대 글자 수 |

```yaml
---
target-characters: 2000
target-tolerance: 100
---
```

모든 목표는 공백 포함 글자 수를 기준으로 계산합니다.

- **범위**: 목표가 `2,000자`, 오차가 `100자`라면 `1,900자`부터 `2,100자`까지 안전 범위입니다. 목표보다 부족하면 `+ 72`, 초과하면 `- 102`처럼 정확한 목표와의 차이를 표시하고, 안전 범위 안에서는 `± 72`처럼 표시합니다.
- **이상**: 기준에 못 미치면 `+ 72`처럼 더 써야 할 글자 수를, 기준을 넘기면 `✓ 128`처럼 기준보다 많은 글자 수를 표시합니다.
- **이하**: 기준을 넘기면 `- 30`처럼 줄여야 할 글자 수를, 기준 안이면 `✓ 270`처럼 남은 여유를 표시합니다.

### 목표 선택과 직접 입력

목표 선택 창에서는 설정에 등록된 후보를 고르거나 목표를 직접 입력할 수 있습니다. 쉼표와 `자`는 무시합니다.

| 입력 | 결과 |
| --- | --- |
| `2000` | 2,000자 범위(오차는 목표의 5%인 `100자`), 2,000자 이상, 2,000자 이하 |
| `2000 100` 또는 `2000±100` | 2,000자 범위, 오차 100자 |
| `1500 이상` 또는 `1500 min` | 1,500자 이상 |
| `3000 이하` 또는 `3000 max` | 3,000자 이하 |

입력이 해석되면 목록 맨 위에 `(직접 입력)` 항목이 나타납니다. 숫자만 입력하면 범위, 이상, 이하 세 항목이 이 순서로 나타납니다. 입력과 똑같은 후보가 이미 있으면 그 후보를 대신 보여 줍니다.

입력 뒤에 `저장` 또는 `save`를 붙이면(`1500 이상 저장`, `1500 저장`) 항목이 `(직접 입력 · 후보에 저장)`으로 바뀌고, 고르면 현재 문서에 지정하면서 설정의 목표 후보 끝에 추가합니다. 같은 종류와 글자 수의 후보가 이미 있으면 저장 항목 대신 그 후보를 보여 줍니다.

설정의 목표 후보도 종류를 범위, 이상, 이하 중에서 고를 수 있습니다.

읽는 시간은 설정한 공백 포함·제외 기준과 분당 읽는 글자 수를 사용합니다. 기본값은 공백 제외, 분당 500자입니다. 가장 가까운 정수로 반올림하고 1분 미만은 `1`로 표시합니다. 읽을 글자가 하나도 없으면 `—`로 표시합니다. 단위는 항목 이름 `읽는 시간(분)`에서 제공합니다.

글자 수를 계산할 때 frontmatter, 코드 블록, 이미지와 임베드, 수식, 태그, 각주는 제외합니다.

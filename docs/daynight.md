# Daynight 사이드바

> 구현 전 명세입니다. 구현은 `src/features/Daynight.ts`에 합니다.

## 역할

잠든 시각과 일어난 시각을 버튼 하나로 기록하고, 오른쪽 사이드바에서 수면 구간을 띠 차트로 보여 줍니다. 하루에 여러 번 자거나 밤낮이 바뀐 경우에도 쓸 수 있도록 날짜별이 아니라 시각이 찍힌 기록 단위로 저장합니다.

## 기록 파일

- 설정한 Daynight 폴더에 월별 파일 `sleep-YYYY-MM.md`로 저장합니다. 예: `sleep-2026-10.md`
- 폴더 설정이 비어 있으면 `sleep` 폴더에 저장합니다.
- 폴더가 없으면 첫 기록을 남길 때 만듭니다.
- 기록은 기록 시각이 속한 달의 파일에 적습니다. 그 달의 파일이 없으면 머리행과 함께 새로 만듭니다.
- 파일 내용은 세 열 마크다운 표이며, 머리행과 값은 사용 언어와 관계없이 영어로 고정합니다.

```md
| Date | Time | Type |
| --- | --- | --- |
| 2026-10-05 | 06:15 | sleep |
| 2026-10-05 | 13:00 | wake |
```

- `Date`는 `YYYY-MM-DD`, `Time`은 24시간제 `HH:mm`, `Type`은 `sleep` 또는 `wake`입니다.
- 플러그인 전용 파일로 보고 새 행은 항상 파일 끝에 붙입니다.

## 읽기와 구간 계산

- 사이드바를 열 때 폴더의 `sleep-*.md` 파일을 모두 읽어 하나의 기록 목록으로 합치고 시간순으로 정렬합니다. 월 경계는 따로 처리하지 않습니다.
- 표 형식에 맞는 행만 읽고 머리행과 다른 줄은 무시합니다.
- 해당 파일이 생성·수정·삭제되면 다시 읽습니다.
- `sleep` 뒤에 오는 `wake`를 짝지어 수면 구간 하나로 만듭니다. 짝이 맞지 않는 행은 건너뜁니다.
- 마지막 기록이 `sleep`이면 현재 시각까지를 진행 중인 구간으로 봅니다.
- 낮잠과 주 수면을 구분하지 않고 같은 색으로 표시합니다.

## 사이드바 구성

위에서부터 다음 순서로 표시합니다.

1. 이동 막대: `<`, 표시 중인 날짜 범위, `>`, `지금`
2. 48시간 띠 차트
3. 요약
4. 최근 기록 5개
5. 기록 버튼

### 띠 차트와 이동

- 48시간 구간을 가로 띠 하나로 그리고, 수면 구간을 막대로 표시합니다.
- 6시간 간격 눈금과 시각을 표시하고, 자정 위치에 날짜를 표시합니다.
- 처음에는 현재 시각에서 끝나는 48시간을 보여 주고, 현재 시각 위치에 세로선을 그립니다.
- `<`와 `>`는 24시간씩 이동합니다.
- 현재 시각 이후로는 이동하지 않고, 가장 오래된 기록 이전으로도 이동하지 않습니다.
- `지금`은 현재 시각 구간으로 돌아갑니다.

### 요약

- 현재 구간을 보고 있을 때
  - 깨어 있으면 마지막 `wake` 이후 경과 시간을 `깨어 있음 8h00`처럼 표시합니다.
  - 자는 중이면 마지막 `sleep` 이후 경과 시간을 `자는 중 3h20`처럼 표시합니다.
  - 지난 24시간 동안의 수면 합계를 함께 표시합니다.
- 과거 구간을 보고 있을 때는 구간 끝 기준 24시간 동안의 수면 합계를 표시합니다.

### 최근 기록

- 가장 최근 기록 5개를 최신순으로 `10/5 13:00 기상` 형식으로 표시합니다.
- 맨 위의 마지막 기록만 클릭할 수 있습니다. 클릭하면 옆에 `×`가 나타나고, `×`를 누르면 그 행을 파일에서 삭제합니다.
- 마지막 기록이 이전 달 파일에 있으면 그 파일에서 삭제합니다.
- 마지막 기록만 지울 수 있으므로 기록은 항상 `sleep`과 `wake`가 번갈아 나옵니다.

### 기록 버튼

- 토글 버튼 하나를 둡니다. 마지막 기록이 `wake`이거나 기록이 없으면 `지금 자기`, `sleep`이면 `지금 일어나기`를 표시합니다.
- 누르면 현재 시각으로 반대 종류의 행을 추가합니다.
- 모바일에서 누르기 쉽도록 사이드바 하단에 넓게 배치합니다.

## 설정과 명령

- 설정 탭에 Daynight 폴더 경로 입력란을 둡니다. Later 노트 대상 폴더 설정과 같은 방식입니다.
- 오른쪽 사이드바에 Daynight 뷰를 여는 명령과 리본 아이콘을 둡니다.
- 사이드바 UI 문구는 플러그인 locales의 en/ko를 따릅니다. 파일에 적는 내용만 영어로 고정합니다.
